# Security

For a suspected vulnerability, first contact [Nstdata](https://www.nstdata.io/) at
[business@nstdata.io](mailto:business@nstdata.io) to arrange a private report.
This is the published general contact address, not a dedicated security inbox.

In the initial message, include the affected package or repository, version or
commit, and a brief description of the impact. Do not post exploit details in
public issues or send API keys, proxy credentials, account data or private page
content. Share a minimal reproduction through the agreed private channel.

Use this repository's issue tracker for non-security bugs. Include the runtime,
expected and actual behavior, and a redacted minimal reproduction.
